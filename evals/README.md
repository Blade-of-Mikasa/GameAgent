# 策略评估

运行 `npm run eval -- --games 10`，比较两个离线策略：

- `first_legal`：总是选择第一个合法动作（演示中为跳过）。
- `prefer_attack`：优先选择出牌，否则选择第一个合法动作。

两者均通过真实 Pi Agent 的规则查询和动作提交工具运行。
报告完成率、胜率、决策超时率、平均耗时、输入/输出 Token 和美元成本，
完整对局和汇总保存在被 Git 忽略的 `runs/evals/`。

这是确定性模拟器上的流程检查。离线模型传输的 Token 为合成数据，
费用为零；这些胜率、耗时和成本不能代表真实模型的牌力或 API 表现。
真实模型运行在 `npm start` 的 live 模式下记录提供商用量和 Pi 的费用估算，
后续可在固定局面集与多随机种子环境中扩展评估器。
